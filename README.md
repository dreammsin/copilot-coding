# About

This repo has no code. It contains a set of simple guides to coding something using code agents like Copilot from an end user perspective rather than a developer approach.

By leveraging Copilot, an end user can produce a personal tool for productivity or utility without having to dive deep into programming. Having this development capability reduces the need for some team to build and add features to apps that fall into the category of personal use. An end user can essentially build an app catering to their own set of unique requirements, given a bit of time and motivation. 

What is sticky in this case are the idea of these tools and the approach to build them. This 'tutorial' is provided to help others follow a set of prescribed steps to help them realize how easy and fun it is to do this themselves.
